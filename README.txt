Geography Quiz PWA

How to use on iPhone:
1. Upload this folder to any HTTPS web host (GitHub Pages, Cloudflare Pages, Netlify, etc.).
2. Open the hosted URL in Safari on iPhone.
3. Tap Share → Add to Home Screen.
4. Launch from the Home Screen. After the first load, the app can work offline.

Important:
- PWA installation/service workers do not work from a local file:// URL on iPhone.
- Quiz statistics are stored in Safari's localStorage for this site.
